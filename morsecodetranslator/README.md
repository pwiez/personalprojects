# Morse Code Translator

This is a simple Morse Code Translator built using Python and Tkinter. It allows you to translate alphanumeric characters and some punctuation into Morse code with a GUI.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/morsecodetranslator.git
    ```
2. Navigate to the project directory:
    ```sh
    cd morsecodetranslator
    ```
3. Create a virtual environment and activate it:
    ```bash
    python3 -m venv venv
    source venv/bin/activate  # On Windows use `venv\Scripts\activate`
    ```
4. Install the required dependencies:
    ```bash
    pip install pyperclip==1.9.0
    ```

## Usage

1. Run the Morse Code Translator:
    ```bash
    python3 morsecodetranslator.py
    ```
2. Enter your message in the text box and click the "Translate to Morse code!" button to see the translation.

3. You can copy the translated message to the clipboard by clicking the "Copy translation to clipboard" button.
